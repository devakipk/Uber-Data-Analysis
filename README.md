# Uber-Data-Analysis
Exploratory Data Analysis of Uber ride booking data using Python, Pandas and Matplotlib.

Uber Data Analysis Project 🚗

Project Title

Uber Data Analysis

Description

This project focuses on analyzing Uber trip data using Python. The main objective is to explore trip patterns, understand travel purposes, analyze trip distances, and visualize useful insights from the dataset.

Project Objective

- Understand Uber trip patterns.
- Analyze business and personal trips.
- Identify frequently used trip purposes and start locations.
- Calculate trip duration and average speed.
- Create meaningful visualizations from trip data.

Dataset

- Dataset Name: Uber Drives 2016 Dataset
- File Format: CSV
- File Name: uber_data.csv

The dataset contains information about Uber trips, including trip purposes, distances, start locations, and other trip-related details.

Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn

Features

- Data Exploration
- Missing Value Handling
- Business and Personal Trip Analysis
- Purpose-wise Trip Analysis
- Average Miles Calculation
- Top 3 Start Locations Analysis
- Trip Duration Calculation
- Average Speed Calculation
- Short, Medium, and Long Trip Classification
- Weekday and Weekend Classification
- Round Trip and One Way Trip Classification
- Data Visualization
- Correlation Heatmap

Visualizations

- Count Plot
- Histogram
- Bar Chart
- Pie Chart
- Correlation Heatmap

Key Insights

- Analyzed trip frequency based on purpose and category.
- Identified the most frequent start locations.
- Compared trip distances across different purposes.
- Analyzed trip duration and average speed.
- Studied trip distribution by day type and trip type.

How to Run

1. Download the project notebook.
2. Open it in Google Colab.
3. Upload the Uber dataset.
4. Run all the cells.
5. View the analysis results and visualizations.

Conclusion

This project helped in understanding Uber trip data through Exploratory Data Analysis (EDA). By using Python libraries such as Pandas, Matplotlib, and Seaborn, different trip patterns, travel purposes, trip distances, and duration were analyzed.

The project provided valuable insights into Uber trips and helped improve practical knowledge of data analysis and visualization.
